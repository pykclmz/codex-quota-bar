# Codex 额度条

## Codex 内的设置页

Windows 1.3.0 可通过本地插件，在 Codex 原生插件页修改主题、显示内容、额度类型、提醒、自动启动和临时隐藏。安装额度条后运行 `windows/install-plugin.ps1`；下载包中该脚本位于解压目录。安装后，聊天框下额度条右键会打开插件详情页。若 Codex 尚未刷新列表，重新打开 Codex 即可。

系统托盘中的额度条图标右键始终打开独立设置窗口，提供备份和备用入口。设置集成采用官方 [Structured Settings](https://github.com/openai/mcp-extensions/blob/main/docs/spec.md#structured-settings)，位于插件详情页，不会在 Codex 的“通用 / 外观”页增加第三方选项。插件通过仅当前 Windows 用户可访问的命名管道共用额度条缓存与偏好，不额外轮询，不打开 HTTP 端口。


双击 `启动额度条.cmd` 或 `CodexQuotaBar.exe` 启动。只启动一份；退出可通过设置窗口的“运行设置”，也可双击 `退出额度条.cmd`。

额度条显示账户实际返回的剩余百分比，前台每 60 秒刷新，后台约每 3 分钟刷新，回到前台后会补取过期数据。当前只返回周额度时，只显示周额度；鼠标悬停可查看重置时间及上次读取时间。重置时间使用北京时间。读取失败后保留上次数据并标记“数据待更新”，紧凑模式用 `~` 标记旧数据；不会把失败当成满额。

新版采用紧凑的无边框状态栏：小圆环表示剩余额度，百分比提高亮度，重置时间降低对比度。默认“融入 Codex 背景”会读取附近少量背景像素匹配颜色，不保存界面截图；也可通过右键 → 外观显示固定为深色或浅色。鼠标移上去会出现轻微圆角底色和右侧设置按钮。

时间区域采用紧凑排版：时钟图标配“X天X小时”，日历图标配“月/日 时:分”，两项之间用细线分隔。不足一天改为小时和分钟，每分钟更新倒计时。到达重置时间会显示“等待额度重置”，额度仍以接口返回值为准。空间不足时先隐藏具体日期，鼠标悬停仍可查看。所有标签和数据统一使用微软雅黑 UI，相同字号、常规字重和像素对齐的绘制高度，整行数字共用同一字体与基线；百分比预留固定宽度，分隔线左右间距一致，按 Codex 的 Windows 系统无衬线风格排版。单周额度在主栏显示倒计时；多个额度窗口的重置详情可在悬停提示里查看。

额度条定位到输入框底部“更改权限”和模型选择按钮之间的空白区域。窗口调整大小、侧栏变化和应用缩放后，会重新读取真实控件位置；旧坐标失效期间短暂隐藏，定位完成后显示。位置稳定时约每 1.5 秒复查控件，首次定位失败时缩短至约 0.6 秒。读取在独立辅助进程中执行，单次最多等待 5 秒，超时会自动重建并重试；窗口尺寸与 DPI 未变时保留最近 6 秒的有效位置，无效结果不会覆盖最近的有效位置。额度条使用普通窗口层级，只紧邻 Codex 上方显示，让输入法候选框和已有弹出窗口显示在它上方，且不抢输入焦点。空间不足时依次精简具体日期、倒计时；连额度本身也放不下时隐藏，详情仍可从托盘查看。

按住额度条左键可在空白区域内微调，偏移相对输入框保存到 `settings.json`，不会再相对整个窗口计算。右键额度条后点击“恢复默认位置”可重新自动对齐。旧版基于窗口的位置设置会自动迁移为新的默认定位。

切换到其他软件、最小化 Codex 时自动隐藏；回到 Codex 自动显示。多个 Codex 窗口时跟随当前使用的窗口。安装本地插件后，右键额度条打开 Codex 内部插件页；未安装时打开独立设置窗口。也可以点击额度条右侧的设置按钮，右键或双击系统托盘图标。

## 1.2.2 设置界面修复

左上角改为 Codex 品牌文字。页面说明、长错误提示和预览自动换行，卡片与底部提示按实际文字高度布局；额度重置详情单独成行，双额度预览完整显示。窄窗口中的帮助按钮自动分行，滚动后可以访问最后一项操作，100% 到 300% 缩放均有布局回归检查。

小分辨率屏幕与高缩放组合下，卡片标题和开关或刷新按钮改为上下排列，操作按钮按实际宽度缩小并增高以显示完整文字；测试包含 1024×768 的可用窗口范围。

手动刷新期间立即禁用重复点击，切换页面或主题后仍保持正确状态；操作成功或失败显示明确反馈，关闭设置后完成的请求不会再访问已关闭窗口。启动状态读取及自动启动设置在后台完成，页面保持可操作；未知/读取失败状态不会显示成“已关闭”，读写完成后统一在界面线程更新。开关、下拉框会同步后台实际状态，自动主题跟随 Codex 背景，主题切换保留当前设置页、滚动位置及提示。

后台启动后首次打开设置窗口会显式恢复窗口可见状态，避免启动方式导致第一次打开时窗口仍被隐藏。

## 1.2.1 窗口移动同步

拖动 Codex 时，通过 Windows 窗口位置事件即时平移额度条，保持相对输入框的偏移，不再等待原有 250 毫秒位置轮询。拖动期间额外启用约 16 毫秒的位置补查，结束拖动后立即停止；静止和后台状态不增加高频轮询。移动只更新坐标，不抢焦点、不改变输入法候选框的优先层级。改变窗口大小或屏幕缩放时，旧输入框位置仍会失效并重新定位。

## 1.2.0 独立设置窗口

右键额度条直接打开带分类侧栏的独立窗口，重复打开会显示同一个窗口。关闭设置窗口不会退出额度条；回到 Codex 后继续显示。窗口支持深色、浅色、系统缩放和滚动布局，小窗口也能访问所有选项。

- **额度概览**：显示各额度窗口的剩余百分比、进度条、北京时间重置日期和倒计时；可切换账户返回的额度类型、手动刷新，并查看连接错误、上次更新和重试时间。
- **外观显示**：选择主题、仅额度/额度和倒计时/完整信息；查看完整的即时文字预览，恢复默认位置。预览不受当前聊天窗口宽度限制，实际额度条会按可用空间精简。
- **额度提醒**：开启或关闭 20% / 10% 的 Windows 低额度通知，查看提醒去重规则。
- **运行设置**：设置随 Windows 登录启动、暂时隐藏额度条，打开使用说明/备份目录，或退出程序。

偏好修改后立即生效并自动保存，写入失败会在页面底部明确提示。暂时隐藏只影响当前运行，重新启动会恢复显示。设置窗口只查看已缓存的额度，打开页面不会增加自动额度请求频率。按 Esc 可关闭设置窗口。

也可运行 `CodexQuotaBar.exe --show-settings` 打开设置；程序已运行时会通知现有实例，不会启动第二份额度条。

## 1.1.0 本地增强版

- 右键“显示内容”可选择仅额度、额度和倒计时、完整信息；空间不足时仍会自动精简。
- 右键可启用“低额度提醒（20% / 10%）”，默认关闭。同一额度窗口和重置周期内，每档仅提醒一次；通知记录会保存，重启后不重复提醒。接口未提供重置周期时不发送提醒。
- 连接错误会区分登录失效、网络、请求超时、CLI 路径及启动权限等情况；失败后按 5、15、30、60、120 秒重试，之后最多每 120 秒一次。悬停可看下次重试时间；“立即刷新”可随时手动重试。
- 系统休眠恢复后会重新定位并重连。前台快速跟随窗口，后台降低检查频率；字体、排版和窗口身份使用缓存。
- 设置通过临时文件替换写入，保留 `settings.json.bak`。主文件损坏时尝试恢复备份，并显示提示；写入失败也会提示。
- 设置窗口侧栏显示程序版本，“运行设置”可打开备份目录。

## 升级与回退

1.1.1 修复了 Codex 重新获得焦点后额度条被压到窗口后面的问题。额度条随 Codex 窗口保持正确层级，仍让输入法候选弹窗优先显示；关闭 Codex 后后台监视继续运行，再次打开时重建显示。

从新版本解压目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1`，默认安装到当前用户的 `AppData\Local\Programs\CodexQuotaBar`。安装前运行自检，备份旧程序后替换并启动；更新失败时尝试恢复备份。自定义安装位置可加 `-InstallDirectory "完整路径"`。

在安装目录双击 `回退上一版本.cmd` 可以恢复最近一次安装前的程序。备份位于 `backups`，`installed-version.json` 记录版本和文件校验值。升级和回退保留现有用户设置。此版本支持本地安装包升级，不会自动下载网络更新。

这是独立的 Windows 悬浮窗口，不修改 Codex 安装文件。可选启用当前账户的 Windows 登录任务。数据通过本机 Codex 的官方 app-server 接口读取，复用现有登录状态；不需要 API Key，不读取或保存聊天正文、密码、令牌。只调用初始化和读取额度接口，不发起模型任务或消耗额度重置奖励。

如果显示连接失败，确认 Codex/CLI 已登录，再右键“立即刷新”。桌面版与 CLI 应登录同一 ChatGPT 账户，首次可能需要在终端执行 `codex login`。分享版会从标准安装位置、正在运行的 Codex 自带 CLI 或 PATH 查找；若仍未找到，可在程序目录新建 `codex-path.txt`，填写本机 `codex.exe` 的完整路径。公司账户或 API Key 登录可能不返回此类额度。

## 自动跟随启动

双击 `开启自动跟随.cmd`，或在设置窗口 → 运行设置开启“随 Windows 登录启动”。程序会立即运行，并在以后登录 Windows 约 20 秒后通过任务计划静默启动（仅当前用户，使用已登录的桌面会话）；Codex 未打开时在托盘等待，不定时读取额度。打开 Codex 后自动定位和读取额度，关闭后继续等待下次打开。无需更换 Codex 快捷方式，也不需要管理员权限。

取消时双击 `关闭自动跟随.cmd`，或在设置窗口关闭该选项；这只取消以后的登录启动，结束当前程序仍可用“退出额度条”。手动退出后，本次登录期间不会自动复活，下次登录才恢复；若需立即恢复，双击“启动额度条”。启用后请保持程序目录不变；移动目录后，在新目录重新运行“开启自动跟随”。

自动跟随采用 Windows 任务计划，名称为 `CodexQuotaBar-当前用户SID`。开启时会迁移本工具旧的 Run 注册表启动项，不改变其他程序。任务不受电池供电影响，不设运行时长上限；异常退出最多按 1 分钟间隔重试 3 次，正常手动退出不会重启。`startup.log` 仅记录最近 100 条启动/退出/异常类型记录，不包含账户或聊天内容，可用于确认登录任务是否执行。

## 维护

主程序源文件为 `QuotaBar.cs`，设置页面为 `SettingsWindow.cs`，窗口移动跟随为 `WindowFollower.cs`。运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1` 编译；使用 Windows 自带 .NET Framework，不需要安装包或下载依赖。

运行 `CodexQuotaBar.exe --self-test` 检查额度解析（结果见 `test-result.json`）。运行 `CodexQuotaBar.exe --diagnose` 读取真实额度并检查 Codex 窗口（结果见 `diagnostics.json`）。诊断文件只保存显示数据和窗口几何，不保存凭证。

窗口层级回归测试：编译后运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\test-window-order.ps1`，结果见 `tests\window-order-result.json`。测试使用屏幕外临时窗口，验证普通和置顶候选窗口均在额度条上方、额度条仍在主窗口上方、不会抢焦点，连续移动中输入框偏移保持不变、拖动结束后停止高频补查，以及主窗口关闭后额度条继续运行；不向 Codex 输入文字。附加 `-Baseline` 可复现旧版置顶逻辑的遮挡问题（预期测试失败）。

可靠性回归测试：运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\test-reliability.ps1`。使用临时设置文件和本地模拟服务，覆盖定位缓存、休眠后的缓存失效、多屏坐标、重试退避、设置损坏恢复、提醒去重，以及登录/网络/断开错误后的重新连接。模拟测试不替代真实输入法、休眠和多显示器验收。这些回归测试已加入 Windows 构建工作流。

设置窗口测试：运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\test-settings-window.ps1`。使用屏幕外临时窗口和模拟额度检查深浅主题、100%–300% 缩放、长文字/双额度/错误提示、小窗口滚动、刷新和自动启动的异步状态、操作失败恢复及真实设置保存；不修改已安装程序的设置和自动启动任务。

## 1.3.1 后台启动修复

启动脚本和安装程序通过 Windows 独立任务启动额度条，避免启动它的临时会话结束时把后台进程一起终止。安装后会检查额度条是否能够响应。按需启动任务没有登录触发器，不会改变自动启动偏好；已开启自动启动时优先使用现有任务。
